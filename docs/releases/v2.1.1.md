# v2.1.1 — the toolkit is now px4-jsbsim-sim2hitl

**In short.** The toolkit's name is now px4-jsbsim-sim2hitl (it was px4-llm-sim2hitl). The new name says what it is: the layer between PX4 and JSBSim. GitHub forwards the old address. PX4, JSBSim, the tools, the recipe format and the checks are as in v2.1.0; what runs is unchanged (simhost builds to the same bytes).

**Upstream versions.** As in v2.1.0: PX4 v1.18.0 (`935addf`) with the patches of `px4/lock.toml`, JSBSim 1.3.3 unmodified.

## Upgrading from v2.1.0

- **Move the toolkit's folder on each computer:** `mkdir -p ~/.cache/px4-jsbsim-sim2hitl && mv ~/.cache/px4-llm-sim2hitl/v2 ~/.cache/px4-jsbsim-sim2hitl/v2`. It holds the board roles, the flash records, the SITL FC builds and the flight runs. Until it is moved, the tools stop and print this command (`tools/paths.py`). Only the `v2` folder moves; the rest of `~/.cache/px4-llm-sim2hitl` is v1's.
- **The PX4 tree setting** is now read from `~/.config/px4-jsbsim-sim2hitl/px4_root` (when `SIM2HITL_PX4_ROOT` is not set). The old file stays where it is, for v1.
- **simhost's default JSBSim prefix** is `~/.cache/px4-jsbsim-sim2hitl/jsbsim-1.3.3-install`. Move the installed JSBSim there, or pass `-DJSBSIM_ROOT`. A simhost build folder configured before the move keeps the old prefix in its CMake cache: configure a new one.
- **A vehicle repository** may update `toolkit` and `repository` in `sim2hitl.lock` to the new name; the old address keeps working.
- **Records and run folders** made before keep naming the old paths. They are not rewritten.
