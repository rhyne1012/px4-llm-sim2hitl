Failed runs kept as evidence (same day, `~/.cache/px4-llm-sim2hitl/v2/runs/`):

- `1805_sitl_…`, `1806_…`: simhost could not bind the simulator port (the vehicle repository's own runtime still held it after its deploy), and an ICMP-refused first send ended the UDP link. The flight script now always shuts the owner down, and UDP links tolerate a peer that is not listening yet. The first run also picked an older ULog of the instance and judged it PASS: the script now takes only a log that appeared after simhost started.
- `1808_sitl_…`: 0.02× real time. The pilot gate stopped at the allowed time, and the pilot wakes only once the time passes its (off-grid, rounded-up) wake-up, so both waited for the pilot's wall-time bound. The gate now steps up to one step past the allowed time, as the vehicle repository's own lockstep worker did.
- `1821_sitl_…`, `1823_sitl_…`: the first recipe's procedure completed and its check passed, but the second run started on the same relay port (its simhost could not bind it) and force-disarmed the first aircraft in loiter. Relay and pilot ports are now per instance, and the script ends the flight when the command script reports complete.

- `1434_hitl_testbird`: after the reboot the Cube came back as `/dev/ttyACM1`. The scripts now take the `/dev/serial/by-id/` path.
- `1435_hitl_testbird`: half of the parameters did not survive the reboot. They had been sent without waiting for each echo, and the reboot came before PX4 stored them. Each parameter is now confirmed, stored (`MAV_CMD_PREFLIGHT_STORAGE`), and only then is the board rebooted.
- `1436_hitl_testbird`: the flight passed, but a failsafe fired 10 s after the takeoff (ULog: `global_position_invalid` stayed set for the first 14 s). PX4 accepted arming before GPS was fused (`COM_ARM_WO_GPS 1`), and the switch to loiter then needed a global position. The scripts now arm only after an absolute horizontal position and a home position.

Known differences between the HITL and SITL rows: the Cube keeps 46 non-default parameters from a vehicle repository's recipes (fixed-wing gains, `FW_PSP_OFF`, geofence, EKF gates), so its roll in the loiter reached 43.6° against 34.7° in SITL. PX4 also commits in-flight accelerometer offsets at disarm, in HITL too; the restore puts them back.
