# v2.1.2 — turbulence in the fast core

**In short.** Every generated fast core now has JSBSim's continuous turbulence (its Dryden types 3 Milspec and 4 Tustin), written once for all vehicles in `fastcore/runtime/turbulence.h`. It is off by default, as in JSBSim, and set with JSBSim's own properties, so one configuration file sets it in the core and in simhost. With the turbulence off, a core computes exactly what it computed before.

**Upstream versions.** As in v2.1.1: PX4 v1.18.0 (`935addf`) with the patches of `px4/lock.toml`, JSBSim 1.3.3 unmodified.

## Upgrading from v2.1.1

Nothing is required.
- A vehicle repository that uses a fast core regenerates it from this version. Its `check.py` now runs the turbulence check (about 7 more minutes); `--skip-turbulence` leaves it out.
- New columns are only appended:
  - 4 parameters: `atmosphere/turb-type`, `atmosphere/turbulence/milspec/windspeed_at_20ft_AGL-fps`, `.../severity`, `simulation/randomseed`;
  - 22 states, before the servo chain;
  - 6 outputs, at the end: `turb_wind_{n,e,d}_mps`, `turb_{p,q,r}_rps`.

  Code that uses column names is unaffected.
- To use the turbulence, give each vehicle of a batch its own `simulation/randomseed`. The core's random numbers are its own, so a run is reproduced from its parameters. Their statistics, not their sequence, match JSBSim's.

## What JSBSim's model leaves out of MIL-F-8785C

The core follows JSBSim, so it leaves out the same things (`fastcore/README.md`, Turbulence):
- The roll-rate turbulence is Yeager's first-order fit, not the Dryden form. At 100 m the variance is about the same, but the power is twice the Dryden form's at 1.5–3 rad/s and 38–49 % of it above 6 rad/s.
- Type 3's v and w filters are first order.
- The low-altitude model uses the altitude above sea level.

## Verified

`docs/verification.md`, the two turbulence rows:
- With the turbulence off, the old columns are bit-identical. Testbird's and a vehicle repository's existing checks give the same numbers as before.
- The core's update agrees with an independent transcription to 7.6e-13.
- Spectra and variances of the core and of JSBSim agree with the formulas within 6 % and 14 % (limits 10 % and 15 %). The first run of that check failed on its estimator; it was fixed without changing the limits, and the failed run is kept.
