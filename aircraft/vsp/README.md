# aircraft/vsp：VSP 氣動表（模型的 `useAVL_VSP = 1`）

模型用的是 AVL 表（[aircraft/avl](../avl/README.md)）；這裡產生另一份用 OpenVSP／VSPAERO 算的表 `model/Skysurfer.mat`，模型初始化檔的 `useAVL_VSP` 設成 1 才會用。2026-11-02 起它由這裡的工具重算，取代來源不明的舊表（舊表沒有幾何檔、方向舵正負號和 AVL 相反，見下面「舊表」）。

| 檔案 | 內容 |
|---|---|
| `skysurfer_geometry.as` | 幾何（OpenVSP 的 AngelScript）：平面形狀和 `SkySurfer_wing2410_NDU.avl` 相同（主翼 NACA 2410、尾翼 NACA 0013、垂尾 NACA 0010，只有升力面、thin surface、沒有機身），加上四個舵面與水平尾翼 1.2° |
| `table.json` | 工況、參考值、求解設定、舵面群組 |
| `run_table.py` | 一個指令：建幾何、跑 VSPAERO 穩定性導數、讀結果、和 AVL 比、轉成模型的 MAT |
| `skysurfer_xcheck.vsp3`、`.vspscript` | 2026-11-02 第一次交叉比對用的最小模型（沒有舵面、尾翼 0°），留作紀錄 |

## 重新產生

```sh
"$PY" -B aircraft/vsp/run_table.py --compare-avl <AVL 的 result.json>          # 算全表（約 1 小時 30 分），什麼都不寫進 model/
"$PY" -B aircraft/vsp/run_table.py --merge-stab <a.stab> <b.stab> --out <新資料夾>   # 中斷過：已算的和補算的合併，不重算
"$PY" -B aircraft/vsp/run_table.py --from-result <run>/result.json --compare-avl <AVL 的 result.json>   # 只重做比較表
"$PY" -B aircraft/vsp/run_table.py --from-result <run>/result.json --write-mat  # 確定了才寫 model/Skysurfer.mat（要 MATLAB）
./runbridge model-cycle                                                          # model/ 改了，接著跑這個
```

- OpenVSP 3.55.0 用 `SIM2HITL_VSP_ROOT` 指定（有 `opt/OpenVSP/vspscript` 的資料夾），沒設時找 `~/.local/share/OpenVSP/3.55.0`。結果放在 cache 的 `vsp_runs/`，或 `--out` 指定的新資料夾。
- 工況和 AVL 表相同：Mach 0.05、0.10 × α −10、−5、0、5、10、15 × β −10、−5、0、5、10；Sref 0.238、Cref 0.2、Bref 1.41、力矩參考點 x 0.05 m（= AVL 的 `Xref`、模型的 `XREF_m`）。
- 每個工況 VSPAERO 求解 12 次：基準、α、β、p、q、r、Mach、U 的擾動，以及四個舵面群組（右副翼、左副翼、升降舵、方向舵）。導數都是每弧度。
- 寫 MAT 時把力矩轉成風軸：VSPAERO 的 `CMl`、`CMm`、`CMn` 是機體軸，模型的 VSP 路徑卻把它們接到輸入軸設成「Wind」的 Aerodynamic Forces and Moments 方塊（AVL 路徑是「Stability」配 Cl'、Cn'）。每個工況的旋轉是常數，所以角速度和舵面的導數照同樣方式轉。`result.json` 和比較表留在機體軸。

## 設定與它們的理由

- **固定尾流**。SkyTalon 的 VSP 是鬆弛尾流（10 次）；這台 18 執行緒的筆電上，鬆弛尾流一個工況 7.4 分鐘，60 個工況要 7 個多小時；固定尾流 76 秒。在 Mach 0.05、β 0 的三個攻角比（鬆弛→固定）：
  | | α 0° | α 5° | α 10° |
  |---|---|---|---|
  | CL | 0.158→0.158 | 0.586→0.588 | 1.011→1.017 |
  | Cm | −0.0646→−0.0648 | −0.188→−0.191 | −0.313→−0.322 |
  | Cmα（VSPAERO 的 d/dα） | −1.40→−1.33 | −1.43→−1.47 | −1.45→−1.51 |
  | Cmq | −12.02→−11.65（3 %） | −12.69→−11.88（6 %） | −13.56→−11.86（12.5 %） |
  | Clp | −0.415→−0.417 | −0.423→−0.415 | −0.433→−0.415（4 %） |
  | Cnr | −0.0734→−0.0774 | −0.0718→−0.0718 | −0.0750→−0.0698（7 %） |
  | 升降舵、右副翼、方向舵 | 差 0.5–2 % | 差 1 % 以內 | 差 1.5 % 以內 |

  巡航（16 m/s 約 α 2.4°）附近差幾 %；攻角越大，固定尾流的俯仰阻尼越偏小（α 10° 少 12.5 %），中性點（α 5→10°）也往後 1.3 % MAC。表照固定尾流算，大攻角的阻尼要打折看；要更準就用鬆弛尾流重算（`table.json` 的 `fixed_wake` 設 false，約 7 小時）。
- **側滑用 β 格點**：VSPAERO 自己的 d/dβ 在兩種尾流之間差很多（Clβ −0.004 對 −0.009），和 SkyTalon 的經驗一樣不可信。模型本來就是查 β 格點，不用 d/dβ；比較表的側滑斜率也用 β ±5° 相減。
- **左側舵面的正負號**：VSPAERO 的鏡像面（左側）同樣的增益會往反方向偏，所以左副翼、左升降舵的增益設成 −1，兩側都是後緣往下為正，和 AVL 檔與模型一致（用 AVL 的副翼、升降舵導數核對過）。方向舵增益 +1 時和 AVL 的 `d04` 同號。
- **每個 β 一個 VSPAERO 程序**，依序跑：一個程序算全部 60 個工況時記憶體一路漲到 22 GB，在 30 GB 的筆電上被 OOM 砍掉。`--jobs N` 可以 N 個同時跑，但這台筆電上 5 個比 1 個慢（每次求解 41 秒對約 9 秒），所以預設 1。全表約 1 小時 30 分。

讀法：

- **縱向幾乎一樣**：升力斜率、Cmq、升降舵在 1–2 % 以內；α 0 的 CL 少 0.018（約 0.2° 攻角），中性點往前 1 % MAC。
- **橫向**：Clp 相同；副翼與方向舵 VSP 多 6–9 %；大攻角時 Cnr 比 AVL 小（15° 是 −0.068 對 −0.076）。
- **側滑差最多**：CYβ 在 VSP 小 16–57 %（攻角越大差越多），Clβ 隨攻角變大得比 AVL 快（5° 是 −0.035 對 −0.023），Cnβ 在 10 % 以內。哪一個對，實飛還回答不了：那一趟沒有方向舵激勵，滾轉也被機身不對稱干擾。
- **阻力**：VSPAERO 的 CD 自帶摩擦阻力的估計，在 α −5～10° 都比 AVL＋0.030 少約 0.0045；`CD_fix_VSP` 因此從 0.065 改成 0.0045，兩條路徑的總阻力相同（差 0.0005 以內），比較時只剩氣動導數的差。

### 模型切到 VSP（`useAVL_VSP = 1`）的配平與模態

另產一份只改 `useAVL_VSP` 的 release（`skysurfer-f0e21a98…`，在暫存的 clone 裡，沒有發布成現用的），用 `sitl/trim.py --plant-lib` 配平與線性化，和現用的 AVL 路徑比（100 m、無風；兩邊和 37 狀態完整模型的差都在 0.5 % 以內，放手 20 s 都不漂移）：

|---|---|---|
| 配平升降舵 13／16／20／25 m/s | 0.353／0.244／0.168／0.120 | 0.353／0.250／0.177／0.131 |
| 配平油門 16 m/s | 0.315 | 0.316 |
| 俯仰角 16 m/s | 2.40° | 2.64° |
| 短週期 | 17.5 rad/s、ζ 0.63 | 17.2 rad/s、ζ 0.64 |
| 長週期 | 0.72 rad/s、ζ 0.13 | 0.71 rad/s、ζ 0.13 |
| 荷蘭滾 | 8.5 rad/s、ζ 0.20 | 8.6 rad/s、ζ 0.16 |

縱向幾乎一樣；橫向的差來自側滑導數（荷蘭滾阻尼、螺旋）。做法：

```sh
# 在專案的另一份 clone 裡把 useAVL_VSP 改成 1，./runbridge update-model --generate && ./runbridge update-model，然後回到這裡：
"$PY" -B sitl/trim.py --plant-lib <clone>/hitl/releases/skysurfer/<平台>/<build-id>/libskysurfer_plant.so --airspeed 16 --linearize
```
