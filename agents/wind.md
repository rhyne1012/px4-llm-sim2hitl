# 風：AI 要先讓使用者知道的事

> 用途：使用者要用風時，AI 先用白話告訴使用者的 8 點，以及哪些由使用者決定。
> 什麼時候讀（必讀）：使用者提到風、或情境裡有 `wind` 時。
> 可以跳過：沒有風的工作。
> 從 [AGENTS](../AGENTS.md) 搬來，原文不改，只改了連結。風的數字、限制與做法在 [plant README](../plant/README.md)「風」。

**風：AI 要先讓使用者知道的事**（數字、限制與做法都在 [plant README](../plant/README.md)「風」，格式見 `plant/wind.py`；這裡只寫要跟使用者說什麼、由他決定什麼）。使用者提到風、或情境裡有 `wind` 時，用白話告訴他下面幾點，再問他要怎麼設；預設值照講，改不改由他決定：

1. **預設是無風**：不寫 `wind` 就和以前一樣。
2. **兩種風二選一**：定常風，或低空風（風切＋陣風＋亂流）；兩種都填時，提醒他定常風沒有作用。
3. **風向是「從哪裡吹來」**（0° = 從北方吹來），只有水平風。
4. **什麼時候開始吹**：預設離地後，地面上和無風一樣。他也可以選指定時間或一開始就吹；選這兩種要先提醒：地上遇到側風會轉向、翻倒，PX4 的起飛前檢查與 EKF 可能報錯或估錯。
5. **陣風不是吹一下就走**：增強到設定大小後一直維持；垂直陣風等於持續的上升或下沉氣流。
6. **亂流的限制**：強度只在 1000 ft（305 m）以下準確；要更高或更精確，得改產碼程式並重新驗證，先確認他需不需要。
7. **看結果**：SITL 的 `trace.csv` 有地速和實際的風；HITL 的提醒在 owner 的 `status` 與每次 run 的紀錄；提醒照樣顯示，不擋。
8. **SITL 與 HITL 比較時**：SITL 的風是真值，HITL 的 FC 要靠 EKF 自己估；兩邊起風的時間、高度與空速不同，實際吹到的風不會逐點相同，比較時寫明起風時間與比較的時段。列出差異，不判通過或失敗，除非事先講好規則。
